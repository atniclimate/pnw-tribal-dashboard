Embedding the Dashboard

Copy a snippet, paste it into a Squarespace Code Block, and a page of the dashboard appears inside the page. Each snippet is one page or view. Unmodified embedding of the published pages is permitted.

Adding It to Squarespace

  1. Edit the Squarespace page and choose where the dashboard should appear.
  2. Add a Code block (Add Block, then Code). Code blocks are not available on every Squarespace plan.
  3. Paste the snippet. Leave Display Source Code unchecked, so visitors see the dashboard instead of the code.
  4. Apply and save. The page shows the dashboard once it is published; the editor preview can look empty.

Use the script line once per Squarespace page, even with several snippets. Without it, each frame keeps the fixed height written in the snippet. The dashboard in the frame always carries its own source and sovereignty notes and a link to open the full page.
